Dusk Garden — a fox gathers three golden fireflies and slips out of a walled garden past gardener-guards and their lantern cones, unseen.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or the arrow keys (or click to stroll), hide behind hedges and bushes, gather all three fireflies, and reach the golden gate.
